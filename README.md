# Student Performance Data Cleaning and EDA

## Project Overview

This project focuses on data cleaning, preprocessing, and exploratory
data analysis of a Student Performance dataset using Python.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset Features

- Student_ID
- Gender
- Age
- Study_Hours_Per_Day
- Attendance_Rate
- Math_Score
- Science_Score
- Extracurricular_Activity

## Data Cleaning

- Identified missing values
- Applied median imputation to numerical columns
- Applied mode imputation to categorical columns
- Checked duplicate records
- Validated data types

## Exploratory Data Analysis

The project includes:

1. Missing Values Visualization
2. Math Score Distribution
3. Math Score Box Plot
4. Correlation Heatmap
5. Study Hours vs Math Score

## Key Findings

Math Score and Science Score showed a moderate positive
relationship, while Study Hours and Math Score showed a very
weak linear relationship in this dataset.
